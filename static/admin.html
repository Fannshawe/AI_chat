Persona YAML 主档案

这里展示并编辑当前主流程实际使用的 Persona。Core 与 Personality 只接受人工维护，Habit 会被 Reflection 自动更新。

Core 修改提案

Reflection 只会提出 Core 修改候选，不会自动写入。你可以在这里批准或拒绝。

AI Memory

这里只维护 AI 自身可被视为事实的长期记忆。它只能来自后台手工录入、YAML 直改或历史资料导入，不会从聊天自动生成。

Contact Memory

这部分来自当前联系人的聊天总结，只保留 episodic / semantic / emotional。Reflection 会自动提取，你也可以手工补充或删除。

关系状态

当前实现会持续维护六个关系维度，并在严重事件时允许阶段降级。这里可以手工确认阶段，同时查看最近变化记录。

暂无阶段说明

关系事件

每次 LLM 判断导致的分值变化都会记录在案，便于检查为什么信任、熟悉度或亲密感发生波动。

情绪记录

置信度低于 0.75 的情绪默认等待人工确认。

聊天指导文档

当前支持 Markdown。本地关键词检索会按章节选取最相关片段。

导入历史聊天

每行格式为“我: 内容”或“对方: 内容”。“我”会记为已发送，“对方”会记为收到。

数据导出

导出联系人、真实聊天、人格、记忆、情绪、关系与生成记录为一个 JSON 文件。

导出全部数据

模型供应商

沿用现有 .env 配置；额外供应商通过 MODEL_PROVIDERS_JSON 声明，密钥不会写入数据库。

默认变量：MODEL_BASE_URL、MODEL_BASE_URL_API_KEY、QWEN_MODEL
可选变量：MODEL_PROVIDERS_JSON
