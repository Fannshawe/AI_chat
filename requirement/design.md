# 软件描述
这个软件是一个恋爱聊天AI。我就想做一个AI模仿我，帮我直接聊天。

# 软件思路
1. 使用fastAPI，有一个简单的页面
2. 有一个node它会记录真实的聊天内容（UI输出的），位于最后面
3. 有多个节点，将node的关键提示词都放到一个提示词文件中。
4. 有个node是人物模块，用来模拟提取一个人的特性，目的是让其他node能根据这个人的特性模仿他
5. 有个node是情感情绪模块，用来记录和用户有关的情感和内容，比如喜好？情感阶段？
6. 有个node是聊天指导模块，它可以根据聊天的上下文，结合指导文档（关键）（word文档），给出指导意见
7. 有个node是聊天内容输出模块，它负责综合以上的内容，给出最后的聊天文字内容，同时保存聊天记忆到本地磁盘（使用langchain的mem功能）
8. 有个node是聊天内容保存模块，也就是`2`说的内容
